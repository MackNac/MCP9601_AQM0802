ラズパイピコによる測定機器スケッチ（MCP9601、BME680、DS3231、SDカードモジュール、AQM0802）。AQM1248との違いはLCDへの表示のみ。
測定、microSDカードへasciiデータとして書き込みを行う。記録時の日時のファイルのタイムスタンプに書き込む

・約1Hzに一度、BME680、MCP9601による気象測定を実施。  
・10回測定毎にmicroSDカードにtimestampと測定データを保存。  
・SDカード書き込みエラーが生じる、またはシステムがフリーズした場合はwatchdog timerによりシステムリセットを発生させる（8秒以内にwatchdog timerをupdateしない場合にリセット）  
・センサモジュールがおかしい（下記の条件に合致する場合）センサモジュールをリセットする。  
_BME680_  
温度、圧力、相対湿度が次の範囲にあることがFAIL_REINIT_THRESHOLD回続けば、BME680をリセット  
  if (t < -40 || t > 85) return false;   // 物理的にあり得ない数値はfalse  
  if (p < 850 || p > 1100) return false; // 物理的にあり得ない数値はfalse  
  if (h < 0 || h > 100) return false;    // 物理的にあり得ない数値はfalse  
全ての測定値がSAME_REINIT_THRESHOLD回連続で同じ値になった場合は、BME680をリセット  

_MCP9601_  
測定値tcが次の範囲にあることがFAIL_REINIT_THRESHOLD回連続で続けば、MCP9601をリセット  
  !isfinite(tc) || tc < -50.0f || tc > 300.0f)  

__tips__    
1.シリアル通信で16桁のyyyymmddhhmmssを入力し実行するといつでも時刻を設定できる（Serial.availを1秒毎にチェックしている）。  

2.SDcardへの書き込みは年月日のフォルダ内に月日.csvのファイル名で書き込む。RTCの日付エラーや日付・日時を保存する配列のエラーにより非アスキー文字がファイル名に入ることを排除するための工夫。該当する月日のフォルダが存在するか確認し、存在しなければ19820504/0504.csvに保存し、ポストプロセスでデータを可能な限り復旧できるようにする。本スケッチにする前にヂュアルCPUでの処理（CPU０で測定、CPU１でSDカード記録）を行なった際に、ファイル名に非アスキー文字が入るバグが発生し、その対策の一つがこの工夫。  

3. SDカード書き込みは10秒に1回であり、それ以外の時刻であれば自由にSDカードを抜くことができる。電源オンにしたままSDカードを抜き、データをPCに保存、再度SDカードを基盤に挿しの直せば、挿した瞬間から通常通り測定が進む。SDカードを抜いた場合は測定を中断し、8秒に1回watch dog timerにより再起動がかかるため、SDカードが挿入され最大8秒後にリセットされる。  

4. LCDへの表示は1行目が年月日時分秒、偶数秒では2行目がBME680の温度と気圧、奇数秒ではBME680の相対湿度とMCP9601の熱電対温度。2行目の表示は0~3セルと4~8セルに分割し、次の表記で出力される。  
偶数秒：TxxxPxxx    
奇数秒：Hxxxtxxx   
xxxには測定値を10倍し小数点以下を切り下げた下3桁の数字が入る。例えば、BME680の温度が34.54℃、気圧が1013.54 hPaと測定された場合、T345P135と出力される。
